# client-app

The Paranoid web app. Setup, commands and configuration are in the [root README](../../README.md).

| Path             | Contents                                                        |
| ---------------- | --------------------------------------------------------------- |
| `src/pages`      | Routes: the landing page (create and join) and the chat page    |
| `src/features`   | Invite, crypto, peer connection, socket and message logic       |
| `src/components` | UI components on native HTML, each with a CSS module, and icons |
| `src/index.css`  | Base styles                                                     |

`~/` is an import alias for `src/`.
